DATA MANAGEMENT

个人数据管理

导出、导入和管理你在本工具中的所有营销计划与任务数据。节日公共数据库不会被覆盖。

本地存储就绪

导出我的数据

将当前浏览器中保存的营销计划和任务记录导出为 JSON 文件，方便迁移或备份。

导入备份数据

选择之前导出的 JSON 文件进行恢复。导入前会检查文件格式，有效数据才会合并。

导入会合并已有数据（按 id 去重），不会自动删除当前数据。

清空所有个人数据

删除本浏览器中全部营销计划、任务记录和自动生成的历史数据。不可恢复。

此操作不影响节日公共数据库。

📦 数据存储说明

• 所有个人数据保存在当前浏览器 LocalStorage 中，仅此浏览器可见。

• 节日公共数据库 (holidays.json、marketing-strategies.json) 与个人数据完全分离，不受导入、导出和清空操作影响。

• 切换年份后，营销计划会保留历史数据，仅日期和倒计时重新计算。

• 建议每次大规模运营结束后导出一份备份。
